# mobile-app-ru-01 architecture

**ID:** `project-architecture` · **Kind:** `index`

## Contents

- [accessibility.md](accessibility.md) — Этот документ владеет адаптацией к системному масштабу текста.
- [analytics.md](analytics.md) — События описывают действие, экран, версию приложения и случайный идентификатор установки. Адреса, токены, текст поиска и полные идентификаторы билетов не отправляются. Буфер очищается после семи дней или выхода пользователя.
- [authentication.md](authentication.md) — Короткоживущий токен доступа находится только в памяти, а ключ обновления — в системном защищённом хранилище. Один координатор объединяет одновременные запросы на обновление сессии. Ответ 401 повторяется ровно один раз после успешного обновления.
- [configuration.md](configuration.md) — В сборку входят адрес API, идентификатор окружения и публичный ключ проверки. Удалённая конфигурация содержит интервалы обновления, лимиты кэша, рекламные параметры и значения по умолчанию для [флагов функций](feature-flags.md).
- [deep-links.md](deep-links.md) — Поддерживаются HTTPS-ссылки `city.example/routes/{id}` и `city.example/tickets/{id}`. Обработчик нормализует путь, отклоняет неизвестные параметры и строит типизированную команду навигации. До готовности корневого координатора хранится только последняя внешняя команда.
- [feature-flags.md](feature-flags.md) — Флаги загружаются после базовой [конфигурации](configuration.md) и имеют встроенные безопасные значения. Новый экран включается только для разрешённой версии приложения. Изменение флага не удаляет локальные данные и не меняет формат базы.
- [image-cache.md](image-cache.md) — Изображения остановок хранятся в памяти и на диске. Дисковый предел применяется по принципу давно не использованных записей; изображения активного билета защищены от вытеснения до конца поездки. Повреждённый файл удаляется и загружается заново.
- [incident-playbook.md](incident-playbook.md) — При массовой ошибке уведомлений дежурный включает флаг `push_campaigns_paused`. Он останавливает создание новых кампаний, но сохраняет регистрацию устройств и замену push-токенов. Уже созданные задания гасятся на сервере; удалять локальные токены запрещено.
- [local-storage.md](local-storage.md) — Приложение использует одну зашифрованную базу на профиль. Таблицы остановок, маршрутов, билетов, избранного и фоновых операций мигрируют до запуска основного интерфейса. Чтение экранов идёт из локальных представлений, поэтому медленная сеть не блокирует навигацию.
- [navigation.md](navigation.md) — Корневой координатор содержит вкладки карты, маршрутов, билетов и профиля. Каждая вкладка сохраняет собственный стек. После нехватки памяти восстанавливается только последний подтверждённый маршрут; модальные окна не восстанавливаются.
- [offline-sync.md](offline-sync.md) — Этот документ владеет правилами разрешения конфликтов при синхронизации.
- [payments.md](payments.md) — Покупка создаёт локальную попытку с уникальным ключом идемпотентности. После возврата из банковского приложения клиент не считает оплату завершённой по самому redirect. Он запрашивает сервер и показывает билет только при статусе `confirmed`. Статусы `pending` и сетевой тайм-аут оставляют попытку для последующей сверки; `declined` завершает её без билета.
- [push-notifications.md](push-notifications.md) — Этот документ владеет регистрацией и заменой токена доставки.
- [README.md](README.md)
- [release-process.md](release-process.md) — Релиз проходит внутреннее тестирование, закрытую группу и поэтапную публикацию 10–50–100 процентов. Повышение доли блокируется при росте аварийных завершений, ошибок запуска или незавершённых платежей.
